## Project Summary: Full-Duplex SPI Master
This peripheral is a full-duplex SPI master controller (Index: 16) designed for high-speed, simultaneous two-way data communication between the TinyQV CPU and external SPI devices.

**Project Information:**
- **Team/Author**: Nguyen Ngoc Hai
- **Mentor**: Nguyen Tri Dung

### Key Features
- **Full-Duplex Communication**: Supports simultaneous transmission (MOSI) and reception (MISO) of 8-bit data per the standard SPI protocol.
- **Automatic CS**: Manages active-low Chip Select automatically during 8-bit transactions.
- **Configurable Clock**: Features a 7-bit programmable divider to support various SPI frequencies.
- **Status Monitoring**: Provides a hardware **BUSY flag** (Bit 0 of Status Register) for CPU synchronization.

### Pinout Mapping (TinyTapeout Standard)
| Signal | Pin | Type | Description |
|:---:|:---:|:---:|:---|
| SCLK | `uo_out[0]` | Output | Serial Clock generated by the master. |
| MOSI | `uo_out[1]` | Output | Master Out Slave In (Data to device). |
| CS_n | `uo_out[2]` | Output | Active-low Chip Select. |
| MISO | `ui_in[0]`  | Input  | Master In Slave Out (Data from device). |

### Register Map
| Address | Name | Access | Description |
|:---:|:---:|:---:|:---|
| `0x00` | **DATA** | R/W | Transmit/Receive data (Writing starts transaction; Reading fetches received byte). |
| `0x01` | **STATUS** | R | Bit 0: BUSY flag (1: In progress, 0: Idle). |
| `0x02` | **DIVIDER** | W | Clock divider for SPI period settings. |

### Testing & Validation
The design is verified using the **cocotb** framework with the following test cases:
- **Clock Speed Verification**: Ensuring BUSY bit timing scales with divider values.
- **Full-Duplex Protocol Timing**: Confirming simultaneous MSB-first data transmission on MOSI and proper data sampling on MISO.
- **Reset Safety**: Verifying asynchronous reset immediately clears BUSY, pulls CS_n high, and clears internal shift registers.
