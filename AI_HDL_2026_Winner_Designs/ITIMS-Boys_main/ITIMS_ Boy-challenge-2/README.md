## Project Summary: Full-Duplex SPI Master
This peripheral is a highly optimized, feature-rich Full-Duplex SPI master controller (Index: 16) designed for high-speed, two-way data transmission between the TinyQV CPU and external peripherals.

### Key Features
* **Full SPI Modes Support**: Hardware configuration for all four SPI modes (CPOL 0/1 and CPHA 0/1).
* **Configurable Word Length & Endianness**: Supports dynamic word lengths from 4 to 8 bits and selectable LSB-first or MSB-first shifting.
* **Optimized Clock Scaling**: Features a 6-bit programmable down-counter to dynamically scale SPI frequencies based on the system clock.
* **Advanced Control**: Includes automated active-low Chip Select (`CS_n`), a manual CS override for multi-byte bursts, and a hardware Transfer-Complete IRQ flag.

### Pinout Mapping
| Signal | Pin | Direction | Description |
| :---: | :---: | :---: | :--- |
| **SCLK** | `uo_out[0]` | Output | Serial Clock generated by the master. |
| **MOSI** | `uo_out[1]` | Output | Master Out Slave In (Data transmitted to device). |
| **CS_n** | `uo_out[2]` | Output | Active-low Chip Select. |
| **IRQ** | `uo_out[3]` | Output | Transfer-Complete Interrupt Request. |
| **MISO** | `ui_in[0]` | Input | Master In Slave Out (Data received from device). |

### Register Map
| Address | Name | Access | Description |
| :---: | :---: | :---: | :--- |
| `0x00` | **DATA** | R/W | TX Data (Write starts transfer) / RX Data (Read latched result). |
| `0x01` | **STATUS** | R/W | Bit 0: `BUSY` flag. Bit 1: `IRQ` flag (Write 1 to clear). |
| `0x02` | **DIVIDER** | R/W | 6-bit clock divider configuration. |
| `0x03` | **CONFIG** | R/W | Sets Word Length, Manual CS, LSB-first, CPHA, and CPOL. |
| `0x04` | **CS_CTRL** | W | Manual CS assertion control. |

### Testing & Validation
The design underwent rigorous verification using the **cocotb** Python framework, encompassing:
* **Timing & Scaling**: Asserting that the SPI period accurately reflects the 6-bit down-counter settings across varying frequencies.
* **Protocol Accuracy**: Cycle-accurate confirmation of MISO sampling and MOSI shifting across all CPOL/CPHA combinations.
* **Reset & Stability**: Verifying asynchronous reset recovery and ensuring configuration registers are locked while the `BUSY` flag is active.
